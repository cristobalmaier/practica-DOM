# Práctica de Manipulación del DOM

Este proyecto es una práctica de manipulación del DOM (Document Object Model) que demuestra diferentes funcionalidades interactivas en una página web.

## Características

El proyecto incluye varios botones con diferentes funcionalidades:

1. **Mensaje Dinámico**
   - Muestra/oculta un párrafo con un mensaje
   - Incluye animación de entrada

2. **Cambiador de Color**
   - Cambia el color de fondo de la página
   - Cicla entre diferentes colores verdes y azules
   - Transición suave entre colores

3. **Contador**
   - Incrementa un contador cada vez que se hace clic
   - Muestra el número actual en el botón

4. **Lista de Ingredientes**
   - Muestra/oculta una lista de ingredientes
   - Animación de entrada para cada elemento
   - Diseño minimalista

5. **Imagen**
   - Muestra/oculta una imagen
   - Animación de entrada

6. **Reloj Digital**
   - Muestra la hora actual
   - Actualización en tiempo real
   - Formato HH:MM:SS

7. **Reproductor de Música**
   - Reproduce música local
   - Control de volumen con deslizador
   - Reproducción en bucle

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
- DOM Manipulation

## Estructura del Proyecto

```
practica-DOM/
```

## Cómo Usar

1. Clona o descarga el repositorio
2. Abre `index.html` en tu navegador
3. Interactúa con los diferentes botones para probar las funcionalidades

## Estilo y Diseño

- Diseño minimalista
- Paleta de colores en verde y azul
- Interfaz intuitiva y responsiva
- Animaciones suaves
- Controles fáciles de usar

## Notas

- El reproductor de música requiere un archivo de audio local
- Las imágenes se cargan desde URLs externas
- El proyecto está optimizado para navegadores modernos
